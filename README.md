# MediCare - Advanced Healthcare Hospital Website

A pixel-perfect, production-grade recreation of the **MediCare** hospital website template ([medicare.prebuiltui.com](https://medicare.prebuiltui.com/)).

Built with clean, maintainable architecture, modern typography (`Geist` & `Urbanist`), responsive layouts, and senior-level smooth micro-interactions.

---

## 🌟 What's Included & Features

1. **Brand Identity & Header**
   - Brand logo (`logo.svg`), full navigation menu (`Home`, `About`, `Services`, `Facilities`, `Book Appointment`).
   - Sticky navbar featuring backdrop blur on scroll (`backdrop-blur-md`).
   - Full mobile navigation drawer with smooth slide-in/out transitions.

2. **Hero Section**
   - Headline: *"Advanced Healthcare for Every Generation"*
   - Social proof / doctor avatar trust stack with real review counts.
   - Dual Call-to-Action buttons with hover micro-animations.
   - Custom hero illustration and decorative grid backdrop.

3. **"Why Choose Us" Feature Bento**
   - Experienced Specialists
   - Patient-First Approach
   - Modern Medical Facilities
   - 24/7 Emergency Care with emergency hotline.

4. **Comprehensive Services Showcase**
   - Complete Primary Care
   - Advanced Cardiac Care
   - Advanced Brain Care
   - Expert Treatment for Bones, Joints & Muscles
   - Compassionate Pediatric Care
   - Immediate Emergency Response

5. **3-Step Appointment Journey**
   - Step 1: Choose a Doctor
   - Step 2: Select Date & Time
   - Step 3: Confirm Appointment & Quality Care

6. **Advanced Facilities Section**
   - Modern Diagnostic Laboratory
   - Advanced Imaging Center
   - Smart Operating Theatres
   - Critical Care & ICU

7. **Interactive FAQ Accordion**
   - Smooth accordion collapse & expand transitions.
   - Animated SVG plus-to-cross rotation (`transform: rotate(45deg)`).

8. **Interactive Booking Engine**
   - Patient name, email, phone number, doctor select, department select, date picker.
   - Client-side validation with feedback styling.
   - Interactive loading state & floating confirmation toast notification.

9. **Health Insights & Articles**
   - Card layout with hover zoom/elevation and category tags.

10. **Global Call to Action & Multi-Column Footer**
    - High-conversion banner with quick booking.
    - Department directories, legal policies, and clinic address.

## 🚀 How to Run Locally

You can open the static file directly or serve it with any local server:

### Option 1: Open directly in your browser
Double-click `public/index.html` or open it with your browser.

### Option 2: Run with Python
\`\`\`bash
cd public
python -m http.server 3000
\`\`\`
Visit \`http://localhost:3000\`

### Option 3: Run with Node.js
\`\`\`bash
npx serve public -p 3000
\`\`\`
